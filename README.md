# Gromov–Witten invariants in Lean

Work in progress on formalising and autoformalising Gromov–Witten invariants.

This project will contain:

- moduli spaces and stacks of stable maps;
- the construction of the virtual fundamental class;
- the supporting theory of curves, stacks, intersection theory, and obstruction theory.

Current progress is recorded in [STATUS.md](STATUS.md).
